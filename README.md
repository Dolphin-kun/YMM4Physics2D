# 「物理演算」プラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/YMM4Physics2D/releases/latest)

## 概要
物理演算アニメーションを追加するプラグインです。

## 使い方
1. アイテムを追加して、`物理`カテゴリーにある「物理演算」を選択して追加してください。

`物理`カテゴリーには、ほかに次のエフェクトがあります。

| エフェクト | 内容 |
| --- | --- |
| 物理ジョイント | 物理演算のアイテムどうし、または空中の点と、ひも・棒・ばね・ヒンジ・固定でつなぎます |
| 物理エリア | アイテムの範囲を風または水の領域にします |
| 物理トリガー | 範囲に触れた物体を消す・止める・弾く・ワープさせます |
| トリガー連動 | 物理トリガーが反応したときに、アイテムを表示したり消したりします |

物理演算エフェクトの「種類」で「液体」を選ぶと、形が流れるように変形します。

重力の強さや向き、画面の端の壁などは、物理演算エフェクトの「ワールド設定」から変更できます。
